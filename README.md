# 🚀 Stock Market Dashboard

A dynamic web application designed to track stock market data and trends for various Indian companies. It provides an interactive dashboard to monitor stock values and company details in a simulated real-time environment.

## ✨ Key Features
- 📈 **Company Tracking:** Includes logos and data for major companies like TCS, SBI, Airtel, ITC, MRF, and DLF `[cite: 2]`.
- 📊 **Dynamic Dashboard:** Utilizes `stock.html` and `stock.js` to dynamically render stock lists and financial details `[cite: 2]`.
- 💾 **Data Management:** Simulates backend data flow and state management using `data.json` and `stock.json` `[cite: 2]`.
- ⚡ **Quick Start:** Features a `start.bat` script for easy, one-click execution on Windows machines `[cite: 2]`.

## 💻 Tech Stack
- **Frontend:** HTML5 (`index.html`, `stock.html`), CSS3, JavaScript (`stock.js`) `[cite: 2]`.
- **Data Structure:** JSON (`stock.json`, `data.json`) `[cite: 2]`.
- **Configuration:** NPM (`package.json`) `[cite: 2]`.
